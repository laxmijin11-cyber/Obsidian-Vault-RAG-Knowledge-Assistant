# JavaScript (JS)

JavaScript is a high-level, interpreted programming language used primarily for web development.
It runs natively in browsers and is used to make web pages interactive (e.g., handling clicks, form submissions, and animations).

**Key Concepts:**
- **Variables:** `let`, `const`, and `var` are used to store data.
- **Functions:** Blocks of code that perform a specific task.
- **Arrays & Objects:** Used to store lists of data and key-value pairs.
- **DOM Manipulation:** Changing the HTML content of a webpage dynamically using the Document Object Model.
- **Promises & Async/Await:** Handling asynchronous operations like fetching data from an API.
